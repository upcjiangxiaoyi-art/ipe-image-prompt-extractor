# 🐚 小海螺 · IPE（Info & Prompt Extractor）

SillyTavern 双管线辅助插件：**生图提取** + **挂账账本**。两条管线互不依赖，只用其中一条也行。

当前版本：`2.34.0` · 每一版改了什么见 [CHANGELOG.md](CHANGELOG.md)

## 上手指南

### 装上

酒馆 → 扩展 → 安装扩展，填本仓库地址，装完刷新页面。

聊天区会多一颗「IPE」小胶囊，点它开面板。面板顶上两页：**🎨 生图**、**📋 挂账**。同样的设置在酒馆「扩展」页的「🐚 小海螺 · IPE」抽屉里也有一份，改哪边都一样。

每个大输入框右上角有个「⤢」，点开是全屏编辑；标题栏上有「复制」「清空」，长模板一键拷走、一键清掉，清空点错了能「↩ 撤销」。

两条管线都要一个「副 AI」来干活（跟你聊天用的主 AI 分开，另填地址和 key）。填 OpenAI 兼容的地址就行，一般以 `/v1` 结尾；Anthropic 官方填 `https://api.anthropic.com/v1`。

用 Anthropic 官方 key 的：生图页 →「API 配置 · 副 AI 连接」→「请求参数」里有个「官方 Claude 走原生接口」，默认关。打开后每楼都发的那份规则按缓存价算（省钱），实况框还能看到思考摘要；生图和挂账都管，中转不受影响。打开后点一下「测试连接」。

### 生图提取：三步

小海螺只负责**把正文变成生图提示词**并贴回楼里；真正出图的是你另装的生图插件（它认楼里的 `<draw>…</draw>` 之类的标记）。

1. **连上副 AI**：生图页 →「API 配置 · 副 AI 连接」→ 填地址、key →「加载模型」选一个 →「测试连接」。
2. **选画风模板**：生图页 →「画风模板」。模板里的 `{Description}` 会被换成提取出来的描述，默认是 `<draw>{Description}</draw>`；你的生图插件认什么标记，模板就包成什么。
3. **提取**：生图页最上面打开「自动提取」，以后每来一楼自动提；再打开「自动注入」就连贴回楼里也自动。想自己把关就关着，点「手动提取」→ 看预览 →「确认注入」。

常用的几样：

- **这张卡 · 角色锚点**：把角色的固定外貌写在这儿，可以「🔒 锁到这张卡」，换卡自动换。
- **画风模板、提取规则 → 🔒 锁到这张卡**：这张卡固定用哪套画风、哪套提取规则，各自锁上以后每次换到这张卡自动切过去；在卡里从下拉临时换一套照常能换。
- **本卡长期指令**：这张卡每次都必须提取的东西（纹身、耳钉之类）。
- **分层提取**：把描述拆成 镜头 / 环境 / 氛围 / 人物 / 动作 五层，每层能单独锁、单独重摇。
- **换画风重注入**：同一段描述换个模板再贴一次，不用重新提取。
- **提取规则 → 正文标签**：默认从 `<content>…</content>` 里取正文，楼里没有这个标签就取整楼。你的预设用别的标签名包正文，就改成那个名字。标签开了没收尾的楼算「没写完」，自动提取、自动挂账会先不跑，免得拿半截正文白花钱。

### 挂账：三步

挂账是让副 AI 每楼替你记一份「账本」（伤、约定、物品、时间线……想记什么你定），再悄悄贴给主 AI 看，主 AI 就不容易忘事。账本不写进正文：楼里能看到一份是只给你看的显示，不进存档。

1. **选副 AI**：挂账页 →「🤖 副 AI 连接」→ 下拉里选一套 API（就是生图页「API 配置」里存的那些；只用挂账的话也先去那儿建一套）→「测试连接」。
2. **写规则**：挂账页 →「📝 挂账规则」。自带一套默认规则，可以直接用，也可以改成你想记的。开新卡时把这张卡的硬设定填进「本卡要点 / 世界观硬设定」。不同的卡用不同的规则，就在那张卡上选好、点「🔒 锁到这张卡」，以后换卡自动切。
3. **打开「自动挂账」**：挂账页最上面。以后每来一楼挂一次。「贴耳注入」默认开着，主 AI 读得到账本。

常用的几样：

- **重新挂账**：这楼挂得不对，重来一次，先预览再采用。
- **对账**：删楼、重 roll 之后账本一般会自己跟着撕掉、回滚；觉得没对上就点一下。
- **🗜 压缩一版**：账本越记越长时，让副 AI 合并支线、精简语言。
- **⏱ 历史与备份 → 后悔药**：改错了从历史版本里换回来；也能导出、导入、从别的聊天继承账本。
- **🎧 贴耳与显示 → 看贴耳**：看主 AI 到底读到了什么。

与枢轨一起使用时，两边保持同名模式即可；小海螺默认监听 `route, ipe_mode`，枢轨输出的 `<route>...</route>` 会同时驱动整套预设和挂账规则，无需再让主 AI 额外写一枚 `<ipe_mode>`。

### 出了问题先看哪

1. **状态行**：两页各有一行字，说它现在在干什么、卡在哪。
2. **🩺 体检**：面板标题栏月亮左边那颗（抽屉里在页签下面）。点开是一页文字：现在的状态、可能有问题的地方、最近发生了什么。看不懂没关系，点「复制」整页发给会看的人；里面不含 key、不含正文。
3. 常见的几种：
   - 新楼来了没自动提取：看生图页状态行，写着「自动提取关着」就去最上面打开。
   - 「拉取模型失败 / API 4xx」：地址、key 或余额的问题，状态行和报错卡里有中转 / 官方回的原话。
   - 挂账挂了但主 AI 像没看见：看「贴耳注入」开没开，用「看贴耳」确认。
   - 手机切到后台再回来像是重置了：Safari 会重新载入页面。账本存在聊天数据里、设置存在酒馆里，都不会丢；正在跑的那一次请求会断，重新点一下就行。

## 双管线

**生图管线**：从 RP 正文提取场景描述，调用独立 API 生成英文生图提示词，可注入回正文（默认包成 `<draw>…</draw>` 追加在楼尾，模板可自定义）。支持多 API 预设一键切换、基础模板 / 角色锚点 / 提取规则 / 双 System Prompt 预设、失败弹窗与一次性自动重试、请求打断。**换画风重注入**：提取结果不动，换个画风模板一键把楼尾那块 `<draw>` 重拼替换，不再调副 AI。注入时把描述和五层记进那楼，每条记过的 AI 楼操作栏里有 🎨，翻到哪楼点哪楼。补充指令可存常用短语，点一下填进去。可选**分层提取**：一次请求拆成镜头 / 环境 / 氛围 / 人物 / 动作五层，每层可锁、可单独重摇，环境层与氛围层在不变时自动沿用上一楼。模板里可以同时写五个层占位符和 `{Description}`：哪一行的占位符全空，那一行整行不输出，分层开关开不开都是同一张模板。

**挂账管线**：由副 AI 维护的不透明账本，仅凭定界符对与 NO_CHANGE 哨兵识别，逐聊隔离，带版本历史回滚（最近 6 版 + 每 10 楼一个里程碑 + 每 100 楼一个里程碑）与缩水保护；删楼、重 roll、改楼都会把已不成立的账撕掉；手动模式走"预览 → 采用 / 重摇"流程。请求走流式接收（思考模型可用），空闲看门狗兜底，不会挂死。副 AI 还在挂账时发下一条，酒馆会先等账落下再送（generate_interceptor）；网络错自动重试一次；同一张卡开新聊天可一键继承上个聊天的账本。账本写长了可以「压缩一版」，副 AI 合并已了结的支线、精简语言，先预览再采用。

## 浮标与状态指示

聊天区快捷入口为「月灰入米霜」SVG 胶囊（涟漪呼吸动效），自由拖动，点击开小面板；亦可由避风塘 Harbor Bar 收编进顶栏泊位，两种形态同一套皮肤。

胶囊自带三种状态指示：

- **雾霾蓝脉冲 + 左侧蓝灯**：挂账进行中——此刻贴耳仍是上一份账本，先别发下一条
- **月灰脉冲**：生图提取进行中
- **右侧绿点**：提取完成、待注入
