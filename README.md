# 🐚 小海螺 · IPE（Info & Prompt Extractor）

SillyTavern 双管线辅助插件：**生图提取** + **挂账账本**。

## 双管线

**生图管线**：从 RP 正文提取场景描述，调用独立 API 生成英文生图提示词，可注入回正文（默认包成 `<draw>…</draw>` 追加在楼尾，模板可自定义）。支持多 API 预设一键切换、基础模板 / 角色锚点 / 提取规则 / 双 System Prompt 预设、失败弹窗与一次性自动重试、请求打断。**换画风重注入**：提取结果不动，换个基础模板一键把楼尾那块 `<draw>` 重拼替换，不再调副 AI。注入时把描述和五层记进那楼，每条记过的 AI 楼操作栏里有 🎨，翻到哪楼点哪楼。补充指令可存常用短语，点一下填进去。可选**分层提取**：一次请求拆成镜头 / 环境 / 氛围 / 人物 / 动作五层，每层可锁、可单独重摇，环境层与氛围层在不变时自动沿用上一楼。模板里可以同时写五个层占位符和 `{Description}`：哪一行的占位符全空，那一行整行不输出，分层开关开不开都是同一张模板。

**挂账管线**：由副 AI 维护的不透明账本，仅凭定界符对与 NO_CHANGE 哨兵识别，逐聊隔离，带版本历史回滚与缩水保护；手动模式走"预览 → 采用 / 重摇"流程。请求走流式接收（思考模型可用），空闲看门狗兜底，不会挂死。

## 浮标与状态指示

聊天区快捷入口为「月灰入米霜」SVG 胶囊（涟漪呼吸动效），自由拖动，点击开小面板；亦可由避风塘 Harbor Bar 收编进顶栏泊位，两种形态同一套皮肤。

胶囊自带三种状态指示：

- **雾霾蓝脉冲 + 左侧蓝灯**：挂账进行中——此刻贴耳仍是上一份账本，先别发下一条
- **月灰脉冲**：生图提取进行中
- **右侧绿点**：提取完成、待注入

## 安装

作为 SillyTavern 扩展安装，或将文件放入扩展目录后重启 / 刷新。

与枢轨一起使用时，两边保持同名模式即可；小海螺默认监听 `route, ipe_mode`，枢轨输出的 `<route>...</route>` 会同时驱动整套预设和挂账规则，无需再让主 AI 额外写一枚 `<ipe_mode>`。
