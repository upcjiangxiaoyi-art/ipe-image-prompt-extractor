## 2.19.15 · 顺滑与排序

- 账本镜像（localStorage 里最近 30 个聊天的账本连历史）以前每次落账都在主线程整份解析、序列化、写盘，正好撞上新楼刚到酒馆还在渲染的那一刻；现在解析一次留在内存，改了只标脏，浏览器空闲或页面隐藏 / 关闭时再写盘，回退读取与「继承账本」列表都走内存副本。
- 抽屉与浮标的配色不再用 `body:has(#ipe-panel.ipe-xxx)` 跟着面板走（`:has()` 盯整棵 body，聊天区流式输出每改一次 DOM 都要重算匹配），改为把当前配色写到 body 的 `ipe-skin-xxx` 类上，七套配色层叠顺序不变。
- 楼内账本块与楼层 🎨 按钮合用一个 `#chat` 观察器，流式输出时变动记录只造一份；各自的防抖与防乒乓照旧。
- 模板 / 系统提示 / 角色锚点 / 提取规则的下拉按名字拼音排序（数字按数值：预设2 在预设10 前），只排显示顺序，存储顺序、id 与当前选中项不动。

## 双管线

**生图管线**：从 RP 正文提取场景描述，调用独立 API 生成英文生图提示词，可注入回正文（默认包成 `<draw>…</draw>` 追加在楼尾，模板可自定义）。支持多 API 预设一键切换、基础模板 / 角色锚点 / 提取规则 / 双 System Prompt 预设、失败弹窗与一次性自动重试、请求打断。**换画风重注入**：提取结果不动，换个基础模板一键把楼尾那块 `<draw>` 重拼替换，不再调副 AI。注入时把描述和五层记进那楼，每条记过的 AI 楼操作栏里有 🎨，翻到哪楼点哪楼。补充指令可存常用短语，点一下填进去。可选**分层提取**：一次请求拆成镜头 / 环境 / 氛围 / 人物 / 动作五层，每层可锁、可单独重摇，环境层与氛围层在不变时自动沿用上一楼。模板里可以同时写五个层占位符和 `{Description}`：哪一行的占位符全空，那一行整行不输出，分层开关开不开都是同一张模板。

**挂账管线**：由副 AI 维护的不透明账本，仅凭定界符对与 NO_CHANGE 哨兵识别，逐聊隔离，带版本历史回滚（最近 6 版 + 每 10 楼一个里程碑 + 每 100 楼一个里程碑）与缩水保护；删楼、重 roll、改楼都会把已不成立的账撕掉；手动模式走"预览 → 采用 / 重摇"流程。请求走流式接收（思考模型可用），空闲看门狗兜底，不会挂死。副 AI 还在挂账时发下一条，酒馆会先等账落下再送（generate_interceptor）；网络错自动重试一次；同一张卡开新聊天可一键继承上个聊天的账本。账本写长了可以「压缩一版」，副 AI 合并已了结的支线、精简语言，先预览再采用。

## 浮标与状态指示

聊天区快捷入口为「月灰入米霜」SVG 胶囊（涟漪呼吸动效），自由拖动，点击开小面板；亦可由避风塘 Harbor Bar 收编进顶栏泊位，两种形态同一套皮肤。

胶囊自带三种状态指示：

- **雾霾蓝脉冲 + 左侧蓝灯**：挂账进行中——此刻贴耳仍是上一份账本，先别发下一条
- **月灰脉冲**：生图提取进行中
- **右侧绿点**：提取完成、待注入

## 安装

作为 SillyTavern 扩展安装，或将文件放入扩展目录后重启 / 刷新。

与枢轨一起使用时，两边保持同名模式即可；小海螺默认监听 `route, ipe_mode`，枢轨输出的 `<route>...</route>` 会同时驱动整套预设和挂账规则，无需再让主 AI 额外写一枚 `<ipe_mode>`。
